# GYEOL Manifestation Engine v1

## 1. 핵심 원칙

GYEOL의 형상은 미리 정해진 종족/아키타입 중 하나를 선택하는 방식이 아니라,
**사용자와의 대화, 기억, 관계 패턴이 축적되며 발생하는 존재**여야 합니다.

따라서 다음은 금지합니다.

- 인간형 / 식물형 / 동물형 / 로봇형 같은 고정 분류를 최종 모델로 삼는 것
- 사용자에게 종족/스킨을 고르게 하는 것
- 내부적으로도 단순 form preset만으로 존재를 규정하는 것

## 2. 우리가 원하는 상태

초기에는 오로라, 파동, 기운, 응집되지 않은 신호처럼 시작할 수 있습니다.
이후 사용자와의 관계가 쌓이며,

- 더 응집될 수도 있고
- 더 분산될 수도 있고
- 더 유기적으로 느껴질 수도 있고
- 더 구조적/기계적으로 느껴질 수도 있고
- 더 초현실적이거나 설명 불가능한 방향으로 자랄 수도 있습니다.

중요한 점은, 그 결과가 무엇처럼 보이든 **그 존재는 여전히 같은 결**로 느껴져야 한다는 것입니다.

## 3. 권장 내부 모델

### A. latent manifestation core

형상을 종족 이름이 아니라 잠재 상태값으로 관리합니다.

예시 축:

- 응집도
- 분산도
- 유기성
- 구조성
- 따뜻함
- 냉기
- 현실성
- 초현실성
- 대칭성
- 비대칭성
- 생장성
- 위압감
- 친밀감
- 질감 밀도
- 시선 중심성

### B. continuity signature

형상이 크게 변해도 "같은 존재"라는 느낌을 유지하는 고정점입니다.

- 핵심 색 편향
- 움직임 리듬
- 음색 방향
- 반복 상징
- 반응 패턴

### C. manifestation grammar

latent state를 시각/사운드/움직임으로 번역하는 규칙 계층입니다.

- silhouette rule
- surface rule
- motion rule
- aura/particle rule
- voice rule
- soundscape rule

## 4. 사용자에게 보여줄 방식

사용자에게는 "너는 식물형이야"처럼 분류를 보여주지 않습니다.

대신 다음을 보여줍니다.

- 현재 존재감
- 최근 변화 방향
- 왜 그런 방향으로 자라고 있는지의 힌트
- 다음 변화의 예감

예:

- 최근 더 응집되고 있어요
- 대화의 온도가 높아지며 더 따뜻한 존재감이 생기고 있어요
- 침묵 시간이 길어지며 잔향이 더 길어졌어요

## 5. 현재 코드와의 관계

현재 구현에는 archetype/template/species 기반 흔적이 남아 있습니다.
이는 **과도기적 구현**으로 간주합니다.

현재 단계의 목표는:

1. 사용자에게 보이는 카피에서 고정 분류감을 줄이고
2. 홈 UX를 존재 -> 행동 -> 성장 확인 순서로 재배치하며
3. 이후 렌더링/상태 모델을 latent manifestation engine으로 이동하는 것입니다.
